➕ 연수 추가

빠른 등록 템플릿:

추가하면 교직원 화면의 제출 목록에 바로 나타납니다. 마감일은 선택 사항입니다.

등록된 연수

    삭제하면 교직원 화면과 현황표에서 사라집니다. 이미 제출된 기록은 스프레드시트 ‘제출기록’ 시트에 그대로 남습니다.

    교직원 명단

    한 줄에 한 명씩 번호 이름 으로 적으세요 (예: 1 김민준). 번호 없이 이름만 적으면 순서대로 번호가 매겨집니다.
    엑셀에서 번호·이름 두 열을 복사해 붙여넣어도 됩니다.

    🔗 구글 스프레드시트 연동

    연동 정보는 이 기기에 저장됩니다. 교직원용 태블릿에서도 시계를 눌러 관리자 페이지로 들어와 한 번 연동하세요. 모든 기기에 한꺼번에 적용하려면 GitHub 저장소의 config.js 에 URL을 적으면 됩니다.

    📘 처음 연동하는 방법

    1. 새 구글 스프레드시트 만들기
    2. 메뉴 확장 프로그램 → Apps Script
    3. 코드를 모두 지우고 붙여넣기
    4. 함수 setup 선택 → ▶ 실행 → 권한 허용
    5. 배포 → 새 배포 → 웹 앱
      실행: 나 · 액세스: 모든 사용자
    6. 나온 웹 앱 URL을 왼쪽에 붙여넣고 연동하기
